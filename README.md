# 🎸 Cancionero de la Tuna

App web interactiva para practicar acordes de guitarra con canciones de la Tuna.

## Características

- **352 canciones** con acordes y letras extraídas del cancionero oficial
- **Acordes resaltados** en rojo sobre la letra (estilo lacuerda.net)
- **Búsqueda** por nombre de canción
- **Navegación alfabética** por letras (A-Y)
- **Tamaño de fuente** ajustable (12px - 36px)
- **Auto-scroll** con velocidad variable
- **Modo oscuro / claro** con persistencia
- **100% offline** - funciona sin conexión a internet
- **Mobile-first** - optimizado para móviles
- **PWA** - instalable desde el navegador

## Uso

### Escritorio
Doble clic en `Abrir.bat` o abre `index.html` en tu navegador.

### Móvil (PWA)
1. Abre `index.html` en el navegador de tu móvil
2. Toca "Añadir a pantalla de inicio"
3. La app aparecerá como una aplicación nativa

### APK Android
Descarga `CancioneroTuna.apk` y安装alo en tu dispositivo Android.

## Tecnologías

- HTML5 + CSS3 + JavaScript vanilla
- Progressive Web App (PWA)
- Service Worker para funcionamiento offline
- Responsive design mobile-first
